### 2. **Модули обработки**

#### CleanerModule (все правила из mainwindow.cpp)
**26 правил**, разделённых по категориям:

**A. HTML-сущности (priority: 1)**
1. `html_nbsp` - `&#160;` → пробел
2. `html_shy` - `&#173;` → удаление
3. `html_tab` - `&#9;` → `&nbsp;`

**B. Пунктуация (priority: 5)**
4. `abbr_td` - `т. д.` → `т.д.`
5. `abbr_tp` - `т. п.` → `т.п.`
6. `abbr_te` - `т. е.` → `т.е.`
7. `abbr_tn` - `т. н.` → `т.н.`
8. `abbr_tk` - `т. к.` → `т.к.`
9. `abbr_ne` - `н. э.` → `н.э.`

**C. CSS-классы (priority: 10)**
10-17. Удаление классов: `Osnova`, `_idEndnoteLink`, `_idFootnoteLink`, `_idEndnoteAnchor`, `_idFootnote`, `_idFootnoteAnchor`, `OsnovaMINUS`, `OsnovaPLUS`

**D. HTML-теги (priority: 15)**
18. `tag_dash` - `<p>— ` → `<p>—&nbsp;`
19. `tag_br` - `<br />` → пробел

**E. Ссылки (priority: 20)**
20. `link_endnote` - `bookDW.html#endnote` → `link2.html#endnote`
21. `link_footnote` - `bookDW.html#footnote` → `link.html#endnote`

**F. Специальные (priority: 25)**
22-26. OTBFMINUS/PLUS, BAMINUS/PLUS → OTBF/BA

**Сложные правила:**
- ✅ `processParaOverride()` - Удаление динамических классов `ParaOverride-XXX`
- ✅ `processTextAnchor()` - Удаление `<a id="_idTextAnchor...">`
- ✅ `processIndexMarker()` - Удаление `<a id="_idIndexMarker...">`
- ✅ `processSpanTags()` - Удаление `<span>`, `<span class="Нет-перенос">`, `<span class="No-break">`

## 📋 Использование

### 1. Первый запуск
1. Запустите BookProcessor.exe
2. Нажмите "Обзор..." и выберите рабочую папку (например, `D:/Books/MyProject`)
3. Программа автоматически создаст структуру:
   ```
   D:/Books/MyProject/
   ├── input/    ← Поместите сюда файлы
   ├── output/   ← Результаты обработки
   ├── config/   ← Конфигурационные JSON
   └── logs/     ← Логи работы
   ```

### 2. Подготовка файлов
- Поместите HTML-файлы в папку `input/`
- Для NotesModule: также положите `LinksReport.txt`

### 3. Настройка модулей
- **Cleaner**: откройте диалог настройки, включите/выключите нужные правила
- **Links**: настройте терминаторы, протоколы, CSS-класс
- **Notes**: укажите путь к файлу отчёта
- **Extractor**: выберите режим и настройте маркеры

### 4. Обработка
1. Отметьте файлы для обработки (или оставьте все)
2. Включите нужные модули (чекбоксы)
3. Нажмите "Обработать файлы"
4. Следите за логом
5. Результаты в `output/`

## 🎨 JSON-конфигурация

Пример `config/default_config.json`:

```json
{
  "cleaner_rules": [
    {
      "id": "html_nbsp",
      "pattern": "&#160;",
      "replacement": " ",
      "enabled": true,
      "use_regex": false,
      "priority": 1,
      "category": "html_entities",
      "description": "Замена неразрывного пробела",
      "user_editable": true
    }
  ],
  "link_options": {
    "enabled_terminators": [" ", ",", "<", ">"],
    "protocols": ["http://", "https://"],
    "css_class": "clickable-link"
  }
}
```

**Редактирование:**
- Через GUI: Cleaner → Настроить → добавить/удалить правило
- Вручную: отредактируйте JSON и перезапустите программу

## 🔍 Логирование

### Уровни:
- `DEBUG` - Детальная отладочная информация
- `INFO` - Общая информация о работе
- `WARNING` - Предупреждения
- `ERROR` - Ошибки
- `CRITICAL` - Критические ошибки

### Файл лога:
`logs/bookprocessor_YYYY-MM-DD.log`

### Формат записи:
```
[2025-12-19 14:32:15] [INFO] [CleanerModule] Применено правил: 26
[2025-12-19 14:32:16] [OK] [CleanerModule] html_nbsp: 45 замен
[2025-12-19 14:32:17] [WARN] [NotesModule] Сноска 'endnote-15' не найдена
```
