# BookProcessor v2.0

Интегрированная система обработки HTML-книг с графическим интерфейсом на Qt6.

## 🎯 Описание

BookProcessor - это мощный инструмент для автоматической обработки HTML-файлов книг перед публикацией. Объединяет 4 специализированных модуля обработки в единый интерфейс.

## 📁 Структура проекта

```
BookProcessor/
├── src/
│   ├── Core/           # Ядро: Logger, PatternEngine, FileManager, ConfigManager
│   ├── Modules/        # Модули обработки (Cleaner, Links, Notes, Extractor)
│   └── GUI/            # Графический интерфейс (MainWindow, ConfigDialog, LogViewer)
├── include/            # Заголовочные файлы
├── resources/          # Иконки и Qt ресурсы
├── config/             # Конфигурационные JSON файлы
└── CMakeLists.txt      # Система сборки
```

## 🔧 Модули обработки

1. **CleanerModule** - Очистка HTML от мусора и исправление форматирования
2. **LinksModule** - Преобразование голых URL в кликабельные ссылки
3. **NotesModule** - Обработка сносок (footnotes/endnotes) по отчёту
4. **ExtractorModule** - Извлечение метаданных о команде создателей книги

## 🛠️ Требования

- **Qt 6.9.1** (MinGW 64-bit)
- **CMake 3.16+**
- **MinGW-w64 13.1.0**
- **Windows 7/8/10/11**

## 📦 Сборка из исходников

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/Lake3L/BookProcessorProgram.git
cd BookProcessorProgram
```

### Шаг 2: Создание папки сборки

```bash
mkdir build
cd build
```

### Шаг 3: Генерация проекта с MinGW

```bash
# Добавляем MinGW в PATH
$env:PATH = "D:\Qt\Tools\mingw1310_64\bin;$env:PATH"

# Генерируем проект
cmake -G "MinGW Makefiles" -DCMAKE_CXX_COMPILER=g++ ..
```

### Шаг 4: Компиляция

```bash
cmake --build . --config Release
```

### Шаг 5: Копирование Qt библиотек

```bash
# Запустите windeployqt для копирования Qt DLL
D:\Qt\6.9.1\mingw_64\bin\windeployqt.exe BookProcessor.exe
```

### Готово!

Теперь `BookProcessor.exe` готов к запуску и содержит все необходимые библиотеки.

## 🚀 Использование

1. **Запустите** `BookProcessor.exe`
2. **Выберите способ работы:**
   - Рабочая папка: укажите папку с файлами
   - Ручная загрузка: добавьте файлы по одному
3. **Настройте выходную папку** (по умолчанию: `рабочая_папка/output`)
4. **Отметьте нужные модули** (Cleaner, Links, Notes, Extractor)
5. **Выберите файлы** чекбоксами в списке
6. **Нажмите "Обработать файлы"**
7. **Результаты** сохранятся в выходную папку
